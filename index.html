What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure content on the web.

It defines the skeletal structure of a webpage, telling the browser where the text, images, and links go. 
<!-- This is an HTML comment -->
<p>Hello World!</p>

Output: Basic Text

01. Root Elements I

<html> – Root of the document.
<head> – Meta information container.
<title> – Browser tab name. 
<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
</html>

02. Root Elements II

<body> – The visible content area.
<meta> – Character set & viewport.
<link> – External CSS/Icons. 
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Visible Content Here</h1>
</body>

08. Multimedia

<video> / <audio> – Embeds media.
<source> – Specifies the media path.

        frameborder="0" allowfullscreen>
</iframe>

<!-- Audio Example -->

</audio>

09. Audio Basics

<audio> – Used for sound files.
Attributes: controls (player), loop (repeat), muted.

  Your browser does not support the audio element.
</audio>

<p style="margin-top:10px; font-size:0.8rem; color:#666;">

</p>
